## 1. 设计定位

**设计读取**:科研开源组织官网首屏,面向地球系统科学的研究者与开源贡献者;视觉中心是一颗写实地球,罩着**海洋、陆地、大气三层六边形模式网格**,云与大气层独立漂移。这是耦合地球系统模式(CESM/MPAS 类)组件图的三维语言:大气壳、陆面、海面,各是独立网格分量。

拨盘:`DESIGN_VARIANCE 7 / MOTION_INTENSITY 7 / VISUAL_DENSITY 3`

### 品牌一致性(核心叙事)

组织 logo = 写实地球 + 带节点网罩(罩子上方还有一层升起的半透明罩)。hero 即 logo 的三维活体:地表双层网格对应贴地网罩,**大气网格笼对应那层升起的罩**。

### 站点级四把锁

| 锁 | 值 | 说明 |
|---|-----|------|
| 主题 | 深色锁定 | 全站 zinc-950 系深色 |
| 强调色 | cyan 家族唯一 | 三层网格用冷色家族递进(海 azure 蓝 → 陆 cyan → 大气冰白);地球贴图自然色不参与锁定 |
| 圆角 | 交互元素全 pill(999px),容器直角(0) | 全站唯一规则 |
| 字体 | Geist(自托管,拉丁子集) | Geist Mono 仅用于数字与代码场景,hero 不用 |

## 4. 地球规格(核心)

### 4.1 数据与资源
- 白天贴图:NASA Blue Marble(equirect jpg);夜面:城市灯光图;云:透明 PNG
- 原型走 CDN(npmmirror / jsdelivr,带回退链),生产自托管压缩
- 三层网格:程序生成;海洋/陆地分类靠采样白天贴图蓝度,**无额外资源**
- 六边形网格构造:测地二十面体细分取对偶,球面拓扑必然含 12 个五边形(真实模式网格特征)

### 4.2 写实地球球体(含昼夜 shader)

| 项 | 规格 |
|----|------|
| 球体 | SphereGeometry(R=2, 96×96 段),equirect 贴图 |
| 昼夜混合 | ShaderMaterial:向日面 = 白天贴图 × 朗伯衰减;背日面 = 城市灯光 ×1.7 + 微弱大陆轮廓;晨昏线 `smoothstep(-0.15, 0.25, dot(n, sunDir))` |
| 太阳方向 | 世界系固定(左上前),自转时大陆依次入夜、城市依次亮起 |
| 光照一致性 | 云层 Lambert 光与 shader 太阳同向 |

### 4.3 云层

双层云壳(1.018R 不透明度 0.75 + 1.030R 不透明度 0.50,图案相互错位 2.1 rad,视觉厚度倍增);透明云贴图,Lambert 受光(夜面云自然变暗);与大气网格笼同组,漂移见 §4.4;贴图失败整层省略。

### 4.4 分层网格系统(v1.4 核心)

| 层 | 半径 | 密度(桌面/移动) | 样式 | 运动 |
|----|------|------------------|------|------|
| **海洋格** | 1.002R | 细分 9(≈1002 格)/ 7 | `#1d76c4` 0.22,节点 `#86c5ee` 0.28 | 随地球刚体 |
| **陆地格** | 1.010R | 同一格架,陆地段 | `#22d3ee` 0.34,节点 `#67e8f9` 0.55 | 随地球刚体 |
| **大气格笼** | 1.17R | 细分 8(≈812 格)/ 6 | `#c9e9f7` 0.22,无节点 | **与云同组,0.012 rad/s 东移** |

- 海洋/陆地分类:每条格线取中点、每个节点取自身位置,采样白天贴图(降采样 1024×512),蓝色占优(`b > r+0.06`)判为海洋
- 陆地格比海洋格高 0.008R:微高差制造地形起伏感,近观可辨
- 层次感四手段:半径分层(大气笼 1.17R 明显悬空,云 1.022R 居中)、色相分离(海 azure 蓝 → 陆 cyan → 大气冰白,冷色家族内递进)、透明度微调、地表刚体 vs 大气组独立漂移
- 大气格笼刻意粗一档:真实模式大气网格常比海洋粗,且视觉上与致密地表拉开辨识度
- 网格随地球拖拽/自转整体旋转;拖拽时地表与大气层的持续错动 = "独立耦合分量"的直观表达

### 4.5 大气边缘与星空

Fresnel rim 1.24R(青,峰值约 0.4,位于大气笼之外);星空约 650 点静态,移动端省略。

### 4.6 废弃方向记录(防止回头路)

| 方案 | 废弃原因 |
|------|----------|
| 体素地球 + 体素云(v1.1-v1.2) | 立方体"玩具感"过强,实测否决 |
| 海洋格做成地下球壳 | 被不透明地球遮挡,不可见;改为同球双层色调 + 微高差 |
| 点阵地形(v1.0) / 写实无网格 | 前者被立体化需求取代;后者缺"模拟"签名 |

## 5. 交互与动效

| 交互 | 规格 | 动机(一句话) |
|------|------|----------------|
| 拖拽旋转 | 水平 + 俯仰(±1.1 rad 钳制),惯性指数衰减;触屏 `pan-y` | 物理反馈,呼应"可交互计算" |
| 自转 | 0.07 rad/s,停止交互 1.5 秒后恢复 | 首屏生命感;大陆入夜依赖自转 |
| 大气组漂移 | 云 + 大气格笼同组 0.012 rad/s 东移 | 大气是流动的独立分量 |
| 指针视差 | 仅 `pointer: fine`;地球 ±0.1 rad,文案反向 8px | 前景/远景层级 |
| 淡入 | canvas 就绪后 1.4s 过渡 | 掩盖贴图加载 |

### reduced-motion 降级(`prefers-reduced-motion: reduce`)

| 项 | 降级 |
|----|------|
| 自转 / 视差 / 大气漂移 / 淡入 | 全部关闭,单帧静态渲染 |
| 拖拽 | 保留,按需重绘,无惯性 |

## 8. 性能、技术栈与部署

### 8.1 性能预算
- LCP < 1.5s(文案即 LCP);CLS = 0;INP < 200ms(拖拽走 rAF)
- 贴图 ≈ 1.5MB 懒加载,生产压缩到 1MB 内;Three.js ≈ 150KB gzip 懒加载
- draw call ≈ 10(地球/双层云/陆线/海线/陆点/海点/大气笼/rim/星空),GPU 负担可忽略
- 原型 CDN 已验证;生产全部自托管

### 8.2 技术栈(D9 已确认)

**Astro 5 + Tailwind CSS 4 + Three.js 岛(vanilla TS)**;项目页 content collections;动效 CSS + IntersectionObserver,无 GSAP。

**vgpu.sh 评估记录(2026-09-13)**:Vercel Labs 的 WebGPU 封装库,非 GPU 云。不用于 hero:无 WebGL 回退、偏底层、零可见收益。WebGPU 升级 = 岛内换 `WebGPURenderer`。将来 Research/Demos 做 serverless 模型演示可再评估。

**部署**:Astro 静态输出 + GitHub Actions → GitHub Pages,仓库建议 `openearthmodelling.github.io`;大陆访问不稳,建议绑自定义域名。
